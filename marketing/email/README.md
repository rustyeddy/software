# Buttondown email series

Keep email drafts here, outside Hugo's content tree. Use numbered Markdown files (e.g. `001-software-engineering.md`) with a subject, status, and body. Markdown is the proposed email delivery format; course sources remain Org.

Draft and review each email through issues and pull requests. Send manually through Buttondown after human approval; record the send date and archive URL in the source. Do not put API keys, subscriber records, or private data in Git. No automatic email delivery is configured.
